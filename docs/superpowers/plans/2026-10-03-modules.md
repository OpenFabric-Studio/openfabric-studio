# Modules and Guided Setup Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development to implement this plan task by task. Preserve contributor changes and leave work uncommitted.

**Goal:** Provide one honest module inventory and recoverable, feature-selected setup from Settings.

**Architecture:** Typed backend catalog owns support checks, dependency planning and installation jobs. Read-only probes never import GPU engines or mutate libraries. The wizard and six compact header indicators consume the same generated contracts and bounded polling store.

**Tech Stack:** FastAPI, Pydantic, SQLite, existing Python installers/process supervisors, Pinia, Vue.
