Noto Sans from Google Fonts, SIL Open Font License 1.1. Copyright and license are in `OFL-NotoSans.txt`. The original font name and file contents are unchanged; only the local filename is shortened.

The default Noto Sans face covers Latin/Greek/Cyrillic. Text containing Han, kana or Hangul uses the pinned pan-CJK Noto Sans CJK SC Regular face, including mixed Latin/CJK captions. The SC regional Han glyph conventions are deliberate; this is not locale-specific typography. Both original files are unmodified and all exports include both font identities.

- Font SHA-256: `2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b`

These are not complete fonts for every Unicode script. Captions are rasterized synchronously before encoding; export provenance includes the font identity. GPU models are not bundled or downloaded by this asset.
